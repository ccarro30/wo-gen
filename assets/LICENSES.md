# Asset provenance

Every binary asset in this repository, where it came from, and how it may be used.
Update this file whenever an asset is added.

| Path | Source | Author | Terms |
|---|---|---|---|
| `vroid/model.vroid` | VroidStudio project | Repository owner | Own creation in VroidStudio |
| `assets/base/base_f01.vrm` | VroidStudio export (VRM 1.0, no reductions) | Repository owner | Own creation; built from VroidStudio parts |
| `assets/base/base_f01_outfit2..5.vrm` | VroidStudio exports of the same body with other clothing | Repository owner | Same as above |
| `assets/base/base_f01_hair2..8.vrm` | VroidStudio exports of the same body with other hairstyles | Repository owner | Same as above |
| `assets/garments/*.blend` | Generated by `wogen harvest` from the exports above (garments and `hair_*` styles) | Derived | Same as the export it was harvested from (see `index.json`) |
| `assets/poses/*.toml` | Saved poses (`pose.save_pose`) | Repository owner | Own data |

## Notes

- The clothing, hair and face parts come from VroidStudio's built-in presets and items.
  VroidStudio's terms allow using models you make with it, but check the current terms of
  use before **redistributing** the models or parts, or using them commercially (⚠ not
  verified here).
- `references/` (third-party screenshots used as a style target) isn't an asset and is never
  committed.
- Don't add marketplace assets that forbid AI use or redistribution, or ripped game/MMD models.
